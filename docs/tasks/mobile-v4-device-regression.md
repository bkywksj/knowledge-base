## 准备

- 设备：Xiaomi 15 Ultra（`adb devices` 应列出），开 USB 调试
- 起调试版：项目路径含中文，Android NDK 的 ld.lld 打不开中文路径，需把 cargo 输出改到纯 ASCII 目录：
  `env TAURI_DEV_HOST=127.0.0.1 CARGO_TARGET_DIR="C:\\cargo-target\\knowledge-base-android" pnpm tauri android dev`
  （启动日志要看到 `Using 127.0.0.1 to access the development server`，见技能 bug-detective）
- 主题：浅色「淡紫」、深色「暖炭」各过一遍；深色时另抽查「纯黑」「琥珀」
- 数据：用测试笔记 / 测试待办，**不在真实笔记上做删除、覆盖类操作**
