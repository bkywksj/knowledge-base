交互说明 · 状态机与原则

状态只存在 Rust 侧一处，所有界面都只是订阅它

全局只有一路下载

状态机放在 Rust 侧单例里；徽章、弹窗、设置页、托盘、多窗口都只订阅同一份状态，并发检查共用一次请求，不会出现两路下载抢一个进度条。

静默，不主动弹窗

自动检查发现新版本只在徽章上显示进度；只有用户手动「检查更新」或点徽章才打开弹窗。待重启时给一次可关闭的提示条。

断点续传 + 自动换源

按 R2 → GitHub 顺序尝试；60 秒没数据算卡住，同源重试几次再换源，已下的字节保留。所有源都失败才进入 error。

下完立即验签

校验通过才进入 ready；不通过就删掉坏包并提示重下，不会出现「点重启一直失败」。

跨重启保留

验签通过的包改成正式文件名，并记下版本和签名；下次启动直接是 ready，不用重下 47.5 MB。新版本启动后清理旧包。

进度节流 ≤ 4 次/秒

Rust 侧按 250ms 合并后推一次完整快照（已下、总大小、速度、剩余时间、当前源）；界面重挂载时先取一次快照再订阅。
